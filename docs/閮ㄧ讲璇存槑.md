# 部署说明

## 1. 后端（Render / 任意服务器）
- 新建 Web Service，连本仓库，Docker 自动构建；或 `docker compose up -d`。
- 环境变量：`FOOTBALL_DATA_TOKEN`（可选，免费注册 football-data.org 可解锁 12 大赛事、历史赛程；不填则走 ESPN 公开接口，若被限流则显示 UNKNOWN）。
- 健康检查：`GET /api/health`。

## 2. 后台定时任务
`scheduler` 容器每小时执行：赛程更新 → 赛前分析+快照 → 赛果结算 → 自动复盘 → 数据源监控。
手机关闭 APP 不影响服务端任务。失败会重试并记录在 `task_logs` 表。

## 3. APK
GitHub Actions 自动构建：`android/` 推送后触发，Artifacts 下载 `football-ai-apk`；Release 页固定地址 v1.0.0。

## 4. 数据库
默认 SQLite（`DB_PATH`），表结构在 `football/pipeline.py` 的 `Store` 建表语句中自动创建。
生产可换 PostgreSQL（把 DB_PATH 换成 DSN 并迁移，接口不变）；Redis 用于缓存（可选）。
