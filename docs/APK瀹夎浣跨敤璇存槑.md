# APK 安装使用说明

1. 打开仓库 Releases → v1.0.0 → 下载 `全球足球智能分析_v1.0.0.apk`。
2. 手机允许“安装未知来源应用”，点击 APK 安装（debug 签名，首次会提示）。
3. 首次打开：首页显示今日比赛。若后端为演示地址，请在「我的 → 后端地址」填自己部署的后端 URL。
4. 底部 6 个 Tab：首页 / 赛事 / 实时 / 赛程 / 排行 / 我的。
5. 点比赛 →「深度分析」生成赛前预测快照 → 可查看「战力雷达 / 概率分析 / AI 报告」。
6. 赛后在「赛后复盘」查看预测 vs 实际；「历史」是全部历史预测记录。
7. 回测、模型实验室在侧边/更多入口（赛程页顶部或首页菜单）。
8. 所有 UNKNOWN 表示无真实数据，不会以 0 或模拟值代替。
